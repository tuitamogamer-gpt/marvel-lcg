# Nova and Ironheart original player pool

This contract covers the **30 printed player-card faces** supplied with Nova and Ironheart: Nova 28010–28020 and 28026–28027, and Ironheart 29014–29027 and 29033–29035. Identity cards, obligations and nemeses belong to the separate identity hosts. Armadillo (28028–28032) and Zzzax (29036–29040) are outside this player-pool import.

Original card faces and physical IDs stay intact. There are four exact Core aliases, verified against all 16 printed rule fields: 28011→01052, 28015→01055, 29021→01072 and 29026→01092. The 26 explicit script faces include two mechanically equivalent non-Core reprints, Morale Boost 29019→05032 and Agent 13 29022→27046. Both have direct actual-printing adapters; changing a physical piece's code is unnecessary.

Primary references are the original [Nova](https://hallofheroeslcg.com/sam-alexander-nova/) and [Ironheart](https://hallofheroeslcg.com/ironheart-riri-williams/) retail cards and the [Rules Reference v1.8](https://cdn.svc.asmodee.net/production-fantasyflightgames/uploads/2026/09/mc_rulesreference_v18_compressed.pdf). RRG v1.8 page 26 specifies that lasting effects update when game state changes and affect later cards that meet the specified set. Consequently Cloud 9 affects later Aerial characters controlled by the chosen player, and “Go for Champions!” protects later Champion characters until that round ends. The same page says Uses discards its source after the last counter is removed **and the effect resolves**. R&D Facility's last research counter is paid immediately; its benefit resolves before the native Uses discard and Pinpoint leave window.

## Payment and costs

`novaIronheartPackRequirements` retains the actual resources required to be **spent**: No Quarter 28013 needs Physical; Honed Technique 28017 and R&D Facility 29020 need two Mental; Go All Out 29017 needs Energy; Push Ahead 29018 needs Mental. Native payment validates these requirements even when discounts reduce the card's resource cost to zero.

Honed Technique and Moon Girl inspect only actual resource allocations **for the card**, excluding excess generation and overpayment. A wild resource allocated as Mental qualifies. Honed Technique uses the event's **printed** cost and applies once to each damage amount dealt by the qualifying Aggression Attack event, including inherited event scripts. The native host applies that modifier centrally; this pure module returns unmodified printed event amounts to prevent double application.

Falcon's Energy is a separate ability SPEND cost after the actual ally attack or thwart. It does not play a card and never doubles a Power resource. Everyday Hero may contribute from its actual owner's hand to another player's payment while that owner's identity has Civilian; its optional healing targets the identity of the player paid for. Ingenuity generates one Mental by exhausting the actual unblanked upgrade in either form.

Go All Out and Push Ahead exhaust the real hero as an additional cost before the labeled effect resolves, including when Stun or Confuse replaces the effect. “Go for Champions!” removes its actual resolving event from the game as the errata's additional cost. Neither cancellation nor later target loss returns paid costs. Removing that event is not a leave-from-play discard and does not trigger Pinpoint.

## Actual receipts and zones

Attack and thwart programs use the native status and target pipeline. No Quarter receives the actual dealt-damage/excess result after native prevention and defeat windows, then discards one actual player card and retrieves that step’s Aggression card before advancing to the next point of excess. Native player-deck exhaustion stops any remaining discard steps and applies the ordinary immediate reset and facedown encounter penalty. Only the exact Aggression IDs discarded by that mill move from discard to hand. Earlier discarded cards and other factions are not retrieved. An earlier red card already recovered stays in hand when a later nonred card exhausts the deck. If the very last card is red, the immediate native reset occurs before the recovery continuation; this implementation recovers only from the current discard pile and never peeks into the newly shuffled deck. This last-red behavior is an interpretation of the RRG immediate-reset rule; no specific official No Quarter ruling for that boundary was located. One by One offers its second packet only after actual defeat, rechecks current Guard/target legality, and retains one labeled attack sequence.

The Locust responds to entering play, including PUT. Moon Girl responds only to actual PLAY from hand and uses its typed payment receipt. Fluid Motion shares its printed Max 1 across all copies for one actual Attack-event PLAY token. Pitchback and Yaw and Roll react to completed **hero** attacks or thwarts, including labeled effects; different copies can respond to the same triggering condition, while the same physical copy cannot. Canceled payment consumes no response receipt.

Snowguard keeps 0–3 physical shift counters on the actual ally. Its conditional printed ATK/THW/HP, Aerial, Overkill and Retaliate disappear when blanked. Vivian blanks only an actual attachment, non-Elite minion or non-permanent side scheme's printed textbox, retaining printed traits, stats and icons. Blanking Tech Theft itself suspends its Tech-player-card blanking, restoring the same physical Photon Blasters' +2 maximum hit points and native ability until the round ends. Ingenuity has Skill rather than Tech and remains available throughout. Blanking and round modifiers expire before end-of-round triggered abilities. A card leaving and reentering play loses its previous targeted modifiers.

Agent 13's 29022 native response readies an actual S.H.I.E.L.D. support, including another player's, after the actual ally attacks or thwarts. It retains the 29022 physical face. Bombshell divides the actual ally attack damage as evenly as possible among all enemies; the controller assigns any remainder. The native host retains one attack and one consequential payment. Wasp's actual unblanked ally bypasses Guard, Patrol and Crisis for her own uses; it grants no bypass to another attacker.

Pinpoint receives an actual still-in-play player-card leave-to-discard receipt. Its ready, unblanked source exhausts as the interrupt cost, and the pending **same physical card** is shuffled into its owner's deck instead. Native leave windows and attached-card cleanup still occur. The interrupt also permits a ready Pinpoint to replace her own impending discard. It cannot replace hand resource discards, encounter cards, returns to hand or removed-game costs.

## Host interfaces

`NovaIronheartPackPorts` supplies native queue, choice, typed payment, real targets, attack/thwart status programs, damage receipts, native player mill, owner-aware moves and pending leave replacements. All queued records are serializable through the ordinary save/load pipeline. `spendUseCost` removes a research counter; `finishUse` performs the ordinary post-benefit Uses cleanup and resumes after any leave interrupts.

The card getters consume `novaIronheartPackCharacterModifiers` for identity and ally stats, HP, Snowguard keywords and Aerial. The native host consumes `novaIronheartPackAttackEventBonus`, `novaIronheartPackWaspIgnores`, `novaIronheartPackAttackDamageReduction`, `novaIronheartPackTextBlank` and `novaIronheartPackCannotTakeDamage`. Derive Snowguard's conditional Aerial directly from her actual counters and blanking state when implementing `hasTrait`, avoiding a trait/modifier recursion. Phase cleanup removes Fluid Motion, Cloud 9 and R&D modifiers; round cleanup removes Patriot, Morale Boost, Vivian and Champions effects at their proper expiration.

## Verification status

The focused suites pass **86 controls: 57 pure and 29 native** (`output/nova-ironheart-pool-certified.log`). Native controls dispatch actual PLAY, PAY, ABILITY and ordinary native effect programs, reloading JSON before each command and retaining every original starter ID. They verify actual typed FOR allocations and overpayment, sole-wild Requirement allocation, source conservation, per-point No Quarter recovery and reset, actual aftermath, ordinary Cloud 9 basic powers, original Agent 13 cooperative support readying, Snowguard/Cloud 9 dynamic Aerial, Uses cleanup timing, Bombshell's single consequential payment, Wasp's actual bypass, Everyday Hero cooperative payment and Pinpoint owner/self replacement. A native Pitchback cancellation control preserves the original trigger and every hand resource ID, retries actual typed payment, returns the played physical copy with Ms. Marvel, excludes that copy from responding again to the original trigger and permits the second copy to respond once. The Vivian/Tech Theft control plays the original Vivian, targets the actual side scheme, verifies the same Photon Blasters' restored effect and ability during that round, then verifies Tech blanking resumes after ordinary native villain-phase and new-round processing without changing the side scheme's printed fields or threat.

The pure controls also cover exact printing equivalence, every dedicated pool face's rule behavior, explicit resource requirements, actual-ID recovery, timing/status replacement, targeted expiration, later-entry lasting sets and saved pending choices. `output/nova-ironheart-pool-style-certified.log` verifies formatting of all four owned files. Full regression, production build, source audit and real browser verification remain release requirements owned by the release coordinator. The No Quarter last-red immediate-reset interpretation is stated above and is not presented as a located card-specific official ruling.
