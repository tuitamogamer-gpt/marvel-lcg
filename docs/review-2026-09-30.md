# Project review and repairs — 30 September 2026

Reviewed baseline: `12d267b`, including the recent tempo, undo, direct-play,
compact-layout, advisor and unfinished onboarding commits. The worktree was
clean before this pass. This is a focused regression review, not exhaustive
certification of every Core Set interaction.

## Confirmed problems and resulting behavior

- **Hidden information and Undo:** Futurist previously displayed three hidden
  cards before the undo boundary advanced. The boundary now advances when
  those cards become visible, preventing a look-and-undo exploit.
- **Advisor fairness:** reshuffling only draw piles preserved the actual
  facedown encounters, pending boosts and drone cards. The planner now samples
  all unknown slots, preserves visible information, and compares candidate
  actions against the same sampled tables. UI hints are discarded when the
  game state changes; pending calculations are canceled on navigation.
- **Payments:** greedy suggestions could spend two double-resource cards for
  a cost of three despite an exact payment being available. The suggestion
  selects the lowest overpayment and then the preferred sources. Affordability
  no longer depends on a 32-source suggestion limit. Paid abilities that cannot
  be funded are excluded from advisor candidates.
- **Identity advice:** Rechannel now describes and checks its actual energy
  payment, heal and draw. Being Stunned no longer prevents the advisor from
  suggesting a basic thwart. Clearing status cards is also considered.
- **Laptop controls:** the pinned hand covered Suit up and Scientist at
  1366×768. The identity, health, stats and abilities now share a compact,
  readable area. Shorter, narrower and populated tables scroll normally.
  Regressions hit-test the actual controls rather than checking only hand and
  villain bounds. The advisor controls remain outside the scrolling text body.
- **Onboarding:** the former unused tutorial definitions now launch a real,
  seeded Spider-Man/Justice versus Rhino/Bomb Scare mission. Seven lessons
  track actual gameplay, retain progress after reload, allow skipping optional
  actions, and can be dismissed without ending the mission. The coach neither
  changes the rules nor advances decisions automatically.
- **Card explanations:** hand cards show concise disabled reasons, and card
  inspection exposes expandable keyboard-accessible keyword explanations.
  Incorrect or incomplete Quickstrike, Retaliate, Overkill, Surge and Uses
  summaries were corrected. The glossary summarizes the rules; printed card
  text remains authoritative.
- **Keyboard isolation:** help and inspection block game Proceed/Undo
  shortcuts. The current action review still accepts Enter. Modal focus traps
  include links and disclosure summaries, filter hidden controls, and only
  respond in the top dialog.
- **Accounts and recovery:** unacknowledged recovery codes stay in hook memory
  through refresh and navigation, until explicitly acknowledged. They are not
  stored in browser storage. Mission records retain the actual start date.
  Snapshot validation rejects inherited card codes and malformed reviews or
  timelines while preserving valid hot-seat and pending-decision saves.
- **Offline play:** the service worker primes the shell, build chunks, fonts
  and landing artwork on the first visit. Cache writes remain alive until
  completion; hashed assets match safely across Vary headers. Artwork refreshes
  in the background and cache cleanup is limited to this application's caches.
  Account requests are never cached.

## Remaining scope

The advisor is still a limited one-turn planner, not a strong-player guarantee.
Production accounts require the existing Redis configuration; provisioning a
database was not part of this pass. Offline artwork is available after it has
been downloaded; unseen cards still need an online visit. Online cooperation,
expansions and an engine module split remain separate work.
